# AOS — открытое тестирование

Пакеты для **macOS на Apple Silicon (arm64), macOS 14+**. На данный момент
проверен macOS 27.0 arm64; macOS 14 и чистая ОС отдельно не проверены.
Для скачивания не нужны GitHub-аккаунт, токен или Apple Developer.
Python включён в пакет; Python/Git/Xcode/CLT у пользователя не требуются.

## Установка в текущую папку

Откройте Terminal в пустой или существующей папке проекта. Выполните блок целиком:

```sh
(
  set -eu
  entry=$(/usr/bin/mktemp -t aos-public-entry)
  /usr/bin/curl -q --fail --silent --show-error --proto '=https' --max-time 60 \
    https://raw.githubusercontent.com/NMF13579/AOS-downloads/66b0a18428c554fc3b0390889f642f93e2eb3c2b/bootstrap.sh -o "$entry"
  actual=$(/usr/bin/shasum -a 256 "$entry")
  [ "${actual%% *}" = "a2f037d9654787f9049ecc8c9c7f901d21f9b5a9a33d11c26e97460ed30a96d4" ] || { echo 'AOS: installer checksum mismatch' >&2; exit 3; }
  /bin/sh "$entry" install "$PWD" test public-test
)
```

Установщик выбирает последний опубликованный **prerelease** канала `test`.
Если выпуск ещё не опубликован или загрузка недоступна, он завершится ошибкой.
`stable` в этом публичном режиме пока отсутствует.

**Тестовый пакет не имеет подписи Developer ID и Apple notarization.**
Доверие — к этому GitHub-источнику по HTTPS. SHA-256 и размер сверяются с GitHub
каталогом версий до запуска, затем проверяется состав пакета. Это не независимая подпись и
не проверка Apple на вредоносный код. Установщик не отключает Gatekeeper и не
удаляет quarantine. Если macOS блокирует компонент, смотрите
[инструкцию Apple](https://support.apple.com/en-gb/102445); не отключайте защиту
системы целиком. Поведение скачанной сборки отмечается в описании выпуска.

Существующие файлы сохраняются, в `AGENTS.md` добавляется управляемый блок.
Чужая папка `aos/` или конфликтующая команда приводят к отказу. Установка
проверяет запуск и состояние перед `APPLIED`, выводит target, канал, версию и
следующий шаг. Задачи вашего проекта не запускаются.

## После установки

```sh
.aos-install/aos status
.aos-install/aos update --check
.aos-install/aos update
.aos-install/aos resume --apply
.aos-install/aos rollback
```

`resume` нужен после прерывания; `rollback` — когда сохранена предыдущая версия.
Обновление сохраняет публичный тестовый источник. Откройте проект в редакторе
и начните с `START_HERE.md`. Проверка native bridge не означает проверенный
пользовательский выбор доступа к файлам.

## Состав и происхождение

Здесь публикуются только переносимый продукт AOS, runtime и сведения о сборке.
История и рабочие материалы AOS-3 не публикуются. Python-код внутри пакета
доступен получателям. `SOURCE.json` и `SOURCE_MANIFEST.txt` фиксируют исходный
рабочий снимок; SHA в теге `aos-…` идентифицирует этот публичный commit записи
сборки. Он не выдаётся за commit незакоммиченных исходников AOS-3.
Лицензии сторонних компонентов сохранены внутри пакета.

Это предварительная сборка для тестирования. Смотрите результаты и ограничения
конкретного выпуска перед использованием; clean-machine и полный native pilot
пока не заявлены.
